# 💜 My Dream Career – Countdown Lock Screen

> A personal countdown to my dream career. Stay focused, track your milestones, and turn your career goals into action.

## 🌐 Live Demo

**Live Project:** [My Dream Career Countdown](https://link.reshare.one/6VTBLiIVpl)

## 📌 About The Project

My Dream Career is a personalized countdown lock screen created to keep my career goals visible and help me stay motivated throughout my learning journey.

The project focuses on an important personal deadline: **31 January 2027**.

It represents my journey towards becoming job-ready, improving my coding skills, building a strong portfolio, and preparing for career opportunities.

The idea is simple: make every day count by keeping the goal in front of me.

## ✨ Key Features

- Live countdown displaying Days, Hours, Minutes, and Seconds.
- Personalized career goal title.
- Target deadline: 31 January 2027.
- Career milestone tracking.
- Motivational design to encourage consistency.
- Clean and visually appealing interface.
- Personal goal-focused lock screen experience.

## 🚀 How to Run Locally

Follow these steps to run the project on your computer.

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder in Visual Studio Code.

3. Install the Live Server extension if it is not already installed.

4. Open `index.html`.

5. Right-click and select **Open with Live Server**.

6. Your project will open in the browser.
